# Play as Pokemon (experimental)

Turn into Ditto or any other Pokémon and walk around as it. It doesn't have to live in your town. Flying Pokémon can fly, and Pokémon with the Grow, Burn, Water or Generate specialty can use it.

| Press | Does |
|---|---|
| **ZL + L3** (left stick click) | Turn into the chosen Pokémon; press again to turn back |
| **ZL + D-pad Left / Right** | Pick the previous / next Pokémon (A to Z). While transformed you change as soon as you stop flicking through |
| **ZR** as a flying Pokémon | Take off, hold to rise |
| **ZL** while flying | Descend; keep holding it on the ground to land |
| **ZL + ZR** while flying | Drop out of the air |
| **ZR** (Pokémon that can't fly) or **ZL + D-pad Down** | Use the Pokémon's ability: Grow, Burn, Water or Generate |

This mod replaces **Always Ditto** and **Play as Resident**. Remove those two before using it: they use some of the same buttons. The Pokopia Editor's **Mods** page does that for you when you press Install or Update.

**Only for Pokopia 2.0.0, update 655360** (build ID `76A489F3BD3642FA`). On any other version the patch is not applied.

## Choosing the Pokémon

**While playing (emulator on Windows).** With the mod installed and the game running, open the editor's **Mods** page, pick a Pokémon under **Change Pokémon while playing** and press **Transform**. No restart is needed. **Turn back** returns you to your character. ZL + L3 then uses the Pokémon you picked last, and ZL + D-pad Left / Right go on from it. Until you pick one, ZL + L3 turns you into Ditto.

**A starting Pokémon.** On the Mods page, change the Pokémon list from **Any (choose while playing)** to one Pokémon and press Install. ZL + L3 then turns you into that Pokémon until you pick another with ZL + D-pad Left / Right. Restart the game after changing it. Use this on a console, where the editor can't reach the running game.

**Without the editor.** ZL + D-pad Left / Right pick any Pokémon while playing. The standalone zips start as Ditto. To start as another Pokémon, open the cheat file `76A489F3BD3642FA.txt` in Notepad, find the line `020F0000 03D14C06 00000046`, and replace `00000046` with your Pokémon's code. [README-standalone.md](README-standalone.md#pokémon-codes) lists the code for every Pokémon. Restart the game after changing it.

The files in this folder are the "Any" setup: `76A489F3BD3642FA.any.txt` is the cheat file it installs, and `76A489F3BD3642FA.txt` is the template for a starting Pokémon (written for Piplup). Both are generated by [re/build/build_v09.py](../../re/build/build_v09.py), which also adds the A to Z list to the patch.

A Pokémon that doesn't live in your town appears a fraction of a second after the transform, because the game has to load its animations first.

On the Mods page, pick one under **Experimental forms** and press **Transform** while the game is running. They are only offered there, not as a starting Pokémon, and the button combos keep using the last Pokémon you picked.

## Flying

Pokémon that hover or fly in the game (Charizard, Scyther, Noctowl, Venomoth, Volbeat, Combee, Vespiquen and others) can fly when you are one of them. You get their own hover and flying animations. Let go of both buttons to hover in place. Other Pokémon ignore the fly buttons.

## Abilities

A transformed Pokémon can use its town specialty: press **ZR**, or **ZL + D-pad Down** (flying Pokémon keep ZR for flying). It plays the Pokémon's own specialty animation and then acts on what is in front of you:

| Ability | Pokémon | Does |
|---|---|---|
| **Grow** | Bulbasaur, Oddish, Snivy, Rowlet, ... (26) | The crops and plants in front of you grow a stage, each once, as when a resident uses Grow |
| **Burn** | Charmander, Vulpix, Torchic, Litwick, ... (34) | The object in front of you is burnt: a campfire lights |
| **Water** | Squirtle, Piplup, Marill, Lapras, ... (37) | Sludge that is not bubbled yet (Bleak Beach) gets Bubbled, with the Bubble animation. Otherwise the Water Gun: it waters soil and plants and washes bubbled sludge away |
| **Generate** | Pikachu, Pawmi, Mareep, Magnemite, ... (27) | The light or machine in front of you is powered |

Each Pokémon uses its own specialty; a Pokémon without one of these does nothing. Burn, Generate and Bubble act as one of the Pokémon living in the area (the game only lets a town Pokémon light a campfire), so a Pokémon must live where you are. Chop, Crush, Recycle and the other specialties are not in: the game does those inside each Pokémon's job routine. Which Pokémon has which specialty comes from the lists on pokopialab.com. Wait until you have finished transforming before you press the button. Hold the combo for a moment: the emulator reads the buttons about 12 times a second.

## Install

The easiest way is the Pokopia Editor's **Mods** page, which installs it straight into your emulator or saves it in the right folder layout.

Without the editor, download a ready-made zip from the [latest release](https://github.com/cycalo/Pokopia-Editor/releases/latest). Each zip includes a short README ([README-standalone.md](README-standalone.md)) that explains how to install it and change the Pokémon.

- [**`z-PlayAsPokemon-emulator.zip`**](https://github.com/cycalo/Pokopia-Editor/releases/latest/download/z-PlayAsPokemon-emulator.zip): unzip into your emulator's `load` folder
- [**`z-PlayAsPokemon-SD-card.zip`**](https://github.com/cycalo/Pokopia-Editor/releases/latest/download/z-PlayAsPokemon-SD-card.zip): unzip onto the root of the SD card

To copy the files by hand instead, use these paths.

### Emulator (Eden, Yuzu and forks)
Copy the files into the emulator's `load` folder like this, then make sure **Play as Pokemon** is ticked in the game's Properties → Add-Ons:

```
load/0400A3A01EE4C000/Play as Pokemon/exefs/76A489F3BD3642FA5E18BD83D32C98BACC5F7D0E.ips
load/0400A3A01EE4C000/Play as Pokemon/cheats/76A489F3BD3642FA.txt
```

Keep **Enable GDB Stub** off, and use the combos only once you're in the world, not on the title screen. The emulator reads the buttons about 12 times a second, so press a combo for a moment rather than tapping it. After a change, the next one waits about 0.75 s: changing form too fast can crash the game.

### Recompia (PC)
Recompia runs the game natively, so it can't use the IPS and cheat files. Use `recompia_play_as_pokemon-1.2.2.pkmod` instead: copy it into Recompia's `mods` folder and allow it in the launcher's Mods page. It has the same buttons, plus a list of every Pokémon on F3 or ZL + R3. The Pokémon can also be picked in the mod's settings (launcher or F1 in game). See [recompia/play-as-pokemon/README.md](../../recompia/play-as-pokemon/README.md).

### Console with custom firmware (untested)
```
atmosphere/exefs_patches/Play as Pokemon/76A489F3BD3642FA5E18BD83D32C98BACC5F7D0E.ips
atmosphere/contents/0400A3A01EE4C000/cheats/76A489F3BD3642FA.txt
```

This has only been tested on an emulator. A stock console can't load patches or cheats, and modding a console can get it banned from online services.

## How it works
The game identifies every character, including you, by a character number: your human form is 1, Ditto is 70, Piplup is 114. `pokemon.json` lists the number for each Pokémon.

The `.ips` patch is applied when the game loads. Each change only acts while a "which form" value is set (0 means off):

1. The player's "desired form" reports that form, and writes to it are forced to that form.
2. The ground check always reports "in a small space", which is where the game normally allows Ditto.
3. Requests to switch back to the normal form are ignored.
4. The player's "something is in the way" animation check always passes, so Ditto's idle never starts the stand-up stretch.
5. The game only loads a Pokémon's animations while that Pokémon lives in your town, and a model without animations is drawn as nothing. So the patch loads the animations of the Pokémon you turn into, then repeats the form change once they are ready.
6. Flying Pokémon have a hover motion, and the game applies no gravity while it plays. Every frame the patch looks at the fly buttons: ZR switches you to the hover motion and sets an upward speed, ZL sets a downward speed, and landing switches you back to the idle motion so the game does its normal fall and landing.

7. Abilities: the residents' specialty actions (Burn 700, Water 703, Bubble 705, Grow 706, Generate 709) only animate when the player asks for them, because the game applies their effect for residents only. Every frame the patch looks at the ability buttons; on a press it plays the action for the animation and, 0.7 seconds later, calls the effect itself on the cell in front of you (found the way the game finds the target of the player's own moves). This part is C (`src/abilities.c`), compiled for the Switch's CPU and placed after the A to Z list by `src/build_abilities.py`.

The patch also holds the A to Z list of Pokémon numbers, in unused space after the game's code. It is an IPS32 patch because that space lies past what a plain IPS can reach.

The cheat file only writes data: it sets the "which form" value and asks the game to switch, and it notes whether ZR, ZL, L3, the D-pad or ZL + D-pad Down is held so the patch can read it. It reads the Pokémon from a second value and keeps its place in the A to Z list, which ZL + D-pad Left / Right step through and the editor sets while the game runs by writing to the emulator's memory. Neither touches your save.
