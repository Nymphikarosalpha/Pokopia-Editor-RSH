# Fork changelog

This file tracks changes specific to this fork. The upstream changelog and history remain intact.

## Unreleased – development preview

### Added

- Resident registration and removal controls.
- Resident home linking, unlinking and island-specific habitat selection.
- Experimental encounter-record creation on checked stage save layouts.
- Event-item preparation for selected event habitats.
- Offline habitat mapping and manual habitat selection.
- Lichii process recognition and standard/nearby portable save detection.
- English-language, neutral RSH menus, warnings and documentation.
- Fork overview and feature/limitations table prominently displayed in README.

### Known limitations

- Special/story Pokémon do not yet have a confirmed direct spawn mechanism.
- Event items are not equivalent to completed event quests.
- Resident removal is not guaranteed to remove an already-persisted world NPC.
- Experimental spawn identifiers and stage edits require further validation.
